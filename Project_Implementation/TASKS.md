# Project Tasks

## Repository setup

- [ ] Initialize `/Project` as a local Git repository.
- [ ] Add a `.gitignore` for C++, CMake, build directories, test artifacts, MinIO data, benchmark output, and editor files.
- [ ] Create the initial commit containing the project documentation.
- [ ] Choose a remote hosting provider and repository name.
- [ ] Create the remote repository.
- [ ] Add the remote URL and push the initial commit.
- [ ] Add a short repository description and the project topics: `database`, `storage-engine`, `buffer-pool`, `wal`, `s3`, `prefetching`, and `ai-infrastructure`.

## Week 1 implementation

- [ ] Create the CMake project skeleton.
- [ ] Add the test framework and first passing test.
- [ ] Implement the page abstraction.
- [ ] Implement the disk manager.
- [ ] Implement the buffer pool and LRU eviction.
- [ ] Add session notes and update the README with verified behavior.

## Open decision

The remote repository cannot be created until the hosting provider and repository name are chosen. The default recommendation is a public GitHub repository with a concise name such as `agent-aware-storage`.
