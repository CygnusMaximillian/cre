# Ticket 001: Repository and Build Foundation

## Status

Open

## Depends on

None

## Objective

Create the local Git repository and a reproducible C++/CMake/test build.

## Tasks

- Initialize Git in the project root.
- Add a C++ `.gitignore`.
- Create the CMake project structure.
- Select and configure GoogleTest or Catch2.
- Add one passing smoke test.
- Document configure, build, and test commands.
- Create the first commit.

## Acceptance criteria

- A clean checkout configures successfully.
- The project builds without warnings treated as errors being introduced.
- The test command passes.
- The README contains the exact build and test commands.
- The initial commit contains only intentional project files.

## Required evidence

Record the configure command, build command, test output summary, and commit hash in the outcome section.
